How do I get an access key?
  1. Go to GitHub → Settings → Developer settings → Fine-grained tokens
  2. Click Generate new token and give it a name (e.g. "website manager")
  3. Under Repository access choose Only select repositories → pick codemdragon/Pharmacy
  4. Under Permissions → Repository permissions → Contents, choose Read and write
  5. Click Generate token and copy it here
